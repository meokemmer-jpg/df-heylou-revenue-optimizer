### Nachfrageprognose
Die Datei `demand_forecaster.py` nutzt Zeitreihenanalyse, um saisonale Trends und Ereignisse abzuschätzen. Dies unterstützt die Voraussage des Bedarfs an Hotelplätzen und ermöglicht eine gezielte Preisgestaltung.

#### Beispiel-Implementierung
Im `demand_forecaster.py` wird ein modellierter Ansatz verwendet, der sowohl saisonale Trends als auch anomalous erkannte Ereignisse berücksichtigt. 

```python
import pandas as pd

class DemandForecaster:
    def __init__(self):
        self.data = None
        
    def load_data(self, file_path):
        self.data = pd.read_csv(file_path)
        
    def forecast_demand(self, date):
        demand_series = self.data['Demand']
        seasonal_trend = demand_series.rolling(window=7).mean()
        daily_seasonality = demand_series.resample('D').median()

        return seasonal_trend[date], daily_seasonality[date]
```
